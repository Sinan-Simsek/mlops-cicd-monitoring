04

Dayanıklılık & kurallar

Startup DB-retry

main.py başlangıçta DB'ye ~60s boyunca yeniden bağlanmayı dener — restart sonrası CoreDNS/Postgres gecikse bile crash etmez.

pool_pre_ping

database.py her havuz bağlantısını kullanmadan test eder — runtime'da Postgres restart olsa bile stale-connection 500'ü yok.

Tek kalite kapısı

CI'da otomatik test yok; kalite kontrolü yalnızca ruff check .. Lint geçmeden image build edilmez.

GitOps değişmezi

Cluster'a elle kubectl apply yapılmaz; git = tek doğru kaynak. selfHeal manuel değişikliği geri alır.
